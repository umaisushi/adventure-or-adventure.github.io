# adventure-or-adventure.github.io
アドベンチャー or アドベンチャ

イラストレーターが飛んだ。締切は今日。 セリフはあるのにイラストがないアドベンチャーゲームを、あなたの絵で完成させるお絵かきゲームです。

ブラウザだけで動きます。インストールも、アカウントも、AIへの接続もいりません。

どんなゲーム？
導入 ― ゲームを作り終えた開発者が、イラストの納品を確認します。ところが担当イラストレーターは音信不通。理由は毎回ちがいます（アカウントが404、旅に出た、納品物が全部猫の写真、原画が船便で南極まわり…）。
お絵かき ― 代打のあなたが、お題とセリフを見ながら5枚のイラストを描きます。締切は1枚90秒。
講評 ― 1枚納品するたびに、アートディレクターが「○○に見える」・点数・ひとことを返します。
完成版プレイ ― あなたの絵にセリフが乗り、ノベルゲームとして再生されます。
世間の声 ― 発売後のニュース見出し、レビュー平均、販売本数、メディアの評価、SNS風の感想、総評、そしてあなたへの称号が出ます。結果は1枚の画像にまとめられます。
特徴
12ジャンル・36本のゲーム

ファンタジー／学園・恋愛／ホラー／ミステリー／お仕事コメディ／青春・ほのぼの／SF・宇宙／時代劇・歴史／どうぶつ・絵本／グルメ・料理／スポーツ・熱血／音楽・ステージ

ジャンルを選ぶと、その中からまだ遊んでいないゲームが出ます。ゲームごとに担当イラストレーター（全員架空）が決まっています。

毎回ちがう展開
導入：チャット、共有ドライブ、メール、SNSの投稿、配送追跡、ニュース速報、ビデオ通話、留守番電話など、内容に合わせた画面で事件が起こります。
追加オーダー：「逆光で」「3色以内で」「画面のどこかに猫を1匹」など。
アートディレクター：辛口、激甘、関西弁、武士、ポエマー、熱血、低血圧、意識高い、おばあちゃん、食いしん坊、探偵の11タイプ。
セリフ：同じゲームでも別バージョンが出ることがあります。
絵に合わせて変わる講評と世間の声

AIは使っていません。描いた絵から次の特徴を読み取り、文章を組み立てます。

いちばん多い色、色数
描かれた範囲の広さ、寄っている方向、縦長か横長か
塗りの量、線の数
使ったブラシ、「元に戻す」の回数
かかった時間、時間切れかどうか
追加オーダーを守れたか（判定できるもののみ）

これをもとに、

「左のほうにいる消えた証拠」「おもちになりかけの探偵」のような見立て
アートディレクターの性格に合わせたコメント
いちばん良かった絵・いちばん謎だった絵を名指しする世間の声
「締切の崖っぷち王」「色彩の暴れん坊」「バケツ職人」などの称号

が決まります。絵の「中身」（何が描いてあるか）までは見ていないので、そこはゲームの味として楽しんでください。

お絵かきツール

ペン／マーカー／えんぴつ／スプレー／消しゴム／バケツ／スポイト、太さと濃さのスライダー、カラーピッカー、元に戻す・やり直す。

遊び方
ジャンルを選んで「はじめる」を押します。「おまかせ」なら全ゲームからランダムです。
会話はクリックか Enter で進みます。
「締切あり」のチェックを外すと、時間制限なしで描けます。
マウスでも、スマホやタブレットの指・ペンでも描けます。
結果画面の「結果を画像で保存」を押すと、結果が1枚の画像として表示されます。長押しや右クリックで保存してください。
